Configurar

Variables necesarias

Crea un archivo .env en la raíz del proyecto y completa estos valores.

Archivo .env

AZURE_F_KEY=tu_clave_de_language_service
AZURE_F_ENDPOINT=https://tu-recurso.cognitiveservices.azure.com

AZURE_CV_KEY=tu_clave_de_computer_vision
AZURE_CV_ENDPOINT=https://tu-recurso.cognitiveservices.azure.com

PORT=3000

Cómo iniciar

  1. Instala dependencias con npm install.
  2. Ejecuta el servidor con npm start.
  3. Abre http://localhost:3000 en el navegador.

Nota de estudio

AZURE_F se usa para Language Service: sentimientos, entidades y resumen. AZURE_CV se usa para Computer Vision: OCR y análisis de imágenes.
